## **Instructions**

The _iterative_ mathematical definition of the factorial function is the following:

```
n! = n * (n - 1) * (n - 2) * (n - 3) * ... * 3 * 2 * 1
```

Keeping this in mind:

- Write the _recursive_ mathematical definition of the factorial function. That is, define `n!` in terms of smaller sub-problems of itself.
- Write a quick Python function implementation of the recursive factorial function. You can call this function `factorial`.
- If you can/want, draw a diagram like the ones we did last class of how a call to `factorial(4)` would break down and resolve itself.
