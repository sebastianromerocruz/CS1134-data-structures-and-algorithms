# **Recursion II**: _Power_

## **Instructions**

The _iterative_ mathematical definition of the power function is the following:


> **`n` * `a` = Π(`i` = 1 to `a`) `n`**

<sup>Where capital pi, **Π**, represents the product instead of the sum.</sup>

Keeping this in mind:

- Write the _recursive_ mathematical definition of the power function. That is, define `n * a` in terms of smaller sub-problems of itself.
- Write the:
    - Base case—when the problem becomes trivial.
    - Recursive hypothesis—how we would break down the power function into a small version of itself.
- Write a quick Python function implementation of the recursive power function. You can call this function `power`.
- Draw a simple [**recursive tree**](https://github.com/sebastianromerocruz/CS1134-data-structures-and-algorithms/tree/main/lectures/06-recursion#examples) demonstrating the runtime of your recursive function.

<sub>**Note**: There are various optimisations for calculating the result of `n` raised to the `a`th power. Simply aiming for Θ(`n`) is totally fine here.</sub>
